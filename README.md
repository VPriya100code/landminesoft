🔗 [(https://landminesoft-eight.vercel.app/)](https://landminesoft-eight.vercel.app/)

## 🧠 About the Project
LandmineSoft is a **fully responsive company website** designed for a modern software development agency.  
It showcases services, careers, authentication, and contact features with a clean UI and smooth user experience.

---

## 🎯 Features
✨ Responsive Design (Mobile + Desktop)  
🔐 Login & Register Authentication  
📄 Multiple Pages (Company Website Structure)  
⚡ Fast Performance with Next.js  
🎨 Modern UI using Tailwind CSS  
📬 Contact & Career Pages
